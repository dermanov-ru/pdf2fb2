# PDF → FB2: чистая конвертация книги

Механику делает CLI-проект **pdf2fb2**: он берёт `pdftotext -layout`, восстанавливает
абзацы по красной строке, расклеивает переносы (сохраняя `во-первых`), чинит буквицы,
вычищает номера страниц, склеивает абзацы через разрывы страниц, отдельно обрабатывает
библиографию (висячий отступ) и вшивает фото (с инверсией Adobe-CMYK, иначе негативы).
**Твоя часть** — суждения, которые нельзя автоматизировать: собрать список глав из
оглавления, выбрать метаданные, решить что выкинуть, визуально сверить пару картинок.

Работает только для PDF **с текстовым слоем** (типографский набор: InDesign/TeX).
Для сканов нужен OCR — это вне инструмента, честно скажи об этом.

## Инструменты и константы
- **CLI:** `/home/mark/llm-projects/pdf2fb2/run.sh` (зови по абсолютному пути, cd не нужен).
  Команды: `diagnose`, `calibrate`, `build`, `verify`.
- **Пример-эталон конфига:** `/home/mark/llm-projects/pdf2fb2/examples/ardzinba.yaml`
  (полностью рабочий, на нём же регрессия). Копируй его под новую книгу.
- **Зависимости** (обычно уже стоят системно): poppler-utils, python3 + Pillow + PyYAML.

## Процедура

1. **Диагностика.** `run.sh diagnose <pdf>`.
   - Смотри «Текстовый слой»: если `~/стр` мало (⚠ скан) — OCR не делаем, останавливаемся
     и говорим пользователю, что тут нужен другой пайплайн.
   - Запомни: сколько изображений, есть ли CMYK, и listing `index→page`.
   - Из выведенного оглавления собери черновик списка глав.

2. **Калибровка отступов.** `run.sh calibrate <pdf>` → возьми предложенные
   `para_min`/`para_max`. (Дефолт 2–6 обычно безопасен.)

3. **Проверь смещение страниц.** Открой `pdftotext -layout -f N -l N <pdf>` для
   стартовой страницы главы из оглавления — печатный номер должен совпасть с PDF-номером.
   Если нет — посчитай offset и сдвинь все start/end.

4. **Напиши `<book>.yaml`.** Копируй `examples/ardzinba.yaml`, заполни:
   - `pdf`, `out_dir`, `title`, `title_short`, `author`, `publish`, `annotation`;
   - `chapters` (title + start/end в PDF-страницах; библиография — `mode: hanging`);
   - `skip:` — разделы, которые выкидываем (именной **указатель** — почти всегда:
     это двухколоночный указатель на печатные страницы, в `-layout` = каша и в
     электронной книге бесполезен; двухколоночные вставки — тоже);
   - `foreword:` — если во фронтматтере есть приветствие/предисловие (маркеры начала/конца);
   - `images:` — `mode: embed`, `cmyk_invert: auto`, `portraits` (страница главы→index),
     `photoblock.first_index`, `cover_index`. Карту index→page бери из `diagnose`.

5. **Сборка.** `run.sh build <book>.yaml --variant both`
   (`text` — только текст, `images` — только с фото, `both` — оба файла:
   `<stem>.fb2` и `<stem>_foto.fb2`). Строка `✓ … XML ok` = порядок.

6. **Контроль качества.**
   - `run.sh verify <fb2>` — well-formed XML + все ссылки на картинки резолвятся.
   - Прочитай первый абзац 2–3 глав: заголовок снят, буквица склеена, нет `вопервых`.
   - Если вшивал фото — открой Read'ом 1–2 картинки из `.pdf2fb2-work/img/rgb/`:
     если негативы — поставь `cmyk_invert: never` (или наоборот `always`) и пересобери.

7. **Отдай результат.** Скажи пользователю пути к файлам и что внутри (главы, число фото,
   что осознанно выкинул и почему). Спроси, скинуть ли файлы в чат.

## Типичные грабли
- **Негативы на фото** → `cmyk_invert` (auto↔never↔always), пересобрать `--variant images`.
- **Абзацы слиплись/разорваны** → не тот `para_min/para_max`, перекалибруй.
- **Библиография/список в один ком** → добавь главе `mode: hanging`.
- **В главу протёк заголовок или мусор из оглавления** → неверные start/end или offset.
- **Ссылки на картинки не резолвятся** (`verify ✗`) → индексы в `portraits`/`photoblock`
  не совпали с реальными; сверься с `diagnose`.
