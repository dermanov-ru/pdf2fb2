# pdf2fb2

[English version](README.en.md)

Конвертер свёрстанных PDF-книг в чистый FB2 и EPUB. Конвертер восстанавливает абзацы, главы, переносы и сноски, а консольная версия переносит ещё и фотографии. Обычные конвертеры вроде Calibre на книгах из InDesign и TeX выдают кашу из строк, этот инструмент сделан как раз для таких книг.

Подходят только PDF с текстовым слоем. Сканам сначала нужно распознавание текста (OCR).

Есть две версии:

- **В браузере:** https://dermanov.ru/pdf2fb2/. Файл никуда не загружается, всё считается на вашем устройстве. На выходе FB2 и EPUB, перед скачиванием книгу можно полистать. Код лежит в [`web/`](web/).
- **Консольная** на Python и poppler, со скиллом для Claude Code. В ней больше ручного контроля: конфиг под книгу, вшитые фотографии.

## Что умеет

- Абзацы определяются по красной строке, а не по строкам вёрстки. Абзац, перенесённый на следующую страницу, не рвётся.
- Переносы склеиваются («охваты-вает» → «охватывает»), настоящие дефисы остаются («во-первых», «по-русски»).
- Буквицы приклеиваются к слову («Р одился» → «Родился»).
- Номера страниц и колонтитулы выбрасываются.
- В списке литературы новая запись начинается от края.
- Сноски переезжают в конец главы и не разрывают абзац.
- Главы берутся из закладок PDF или по крупным заголовкам, названия глав пишутся как в печатном оглавлении.
- Название и автор берутся с титульного листа.
- Шрифты без таблицы букв (ToUnicode), из-за которых вместо текста получаются «ŰŬŖ», расшифровываются. Для PT Serif есть точная таблица, поэтому правильно встают и абхазские буквы.
- Консольная версия разворачивает Adobe CMYK-картинки, которые `pdfimages` выгружает негативами.

## Консольная версия

Нужны `poppler-utils` (`pdftotext`, `pdfimages`, `pdfinfo`) и Python 3 с Pillow и PyYAML. Если чего-то нет, `run.sh` скажет об этом.

```bash
# 1. Проверить, что текстовый слой есть, и получить заготовку оглавления
./run.sh diagnose  book.pdf

# 2. Подобрать пороги красной строки
./run.sh calibrate book.pdf

# 3. Написать book.yaml: скопировать examples/ardzinba.yaml, поправить главы и метаданные

# 4. Собрать <имя>.fb2, а с фото ещё и <имя>_foto.fb2
./run.sh build book.yaml --variant both     # text | images | both

# 5. Проверить FB2: корректный XML, все картинки на месте
./run.sh verify book.fb2
```

`examples/ardzinba.yaml` — рабочий конфиг для книги В. Г. Ардзинбы «Моя жизнь» (512 страниц, 90 фотографий). На этой книге инструмент собирался и проверялся.

Скилл `skill/SKILL.md` нужно скопировать в `~/.claude/skills/pdf-to-fb2/` и указать в нём путь к `run.sh`. Дальше Claude Code сам проведёт книгу по шагам: механику делает CLI, а решения, которые нельзя автоматизировать (что выкинуть, какие фото к каким главам), принимает агент вместе с вами.

Устройство и границы применимости описаны в `SDD.md` (на английском).

## Версия для браузера (`web/`)

TypeScript поверх [pdf.js](https://github.com/mozilla/pdf.js) (`pdfjs-dist` 6.x, legacy-сборка). Конфиг под книгу не нужен: всё определяется по координатам текста.

| Файл | Что делает |
|------|------------|
| `extract.ts` | строки, кегль основного текста, отступы, буквицы, колонтитулы, главы, сноски, название и автор |
| `textproc.ts` | сборка абзацев и склейка переносов (порт `textproc.py`) |
| `glyphfix.ts`, `ptserif-order.ts` | расшифровка шрифтов без таблицы букв |
| `pdfjs-patch.mjs` | плагин Vite, патчит воркер pdf.js: длинное тире, закодированное широким U+00AD, иначе теряется |
| `fb2.ts`, `epub.ts` | сборка FB2 2.0 и EPUB 3 (архив — [fflate](https://github.com/101arrowz/fflate)) |
| `browser.ts` | запуск pdf.js: воркер, cMaps, стандартные шрифты |

Сама страница с интерфейсом живёт в репозитории сайта, здесь лежит её ядро.
